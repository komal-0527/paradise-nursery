# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application built using React and Redux.

## Features

- Browse houseplants by category
- Add plants to cart
- Increase/decrease quantities
- Remove products from cart
- Dynamic cart count
- Responsive design

## Technologies Used

- React.js
- Redux Toolkit
- CSS
- JavaScript
- Vite

## Project Name

Paradise Nursery Shopping Application
